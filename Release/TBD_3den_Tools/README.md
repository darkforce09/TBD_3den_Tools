# TBD 3den Tools

Eden Editor extension for mission optimization and composition management.

This folder is the packaged, ready-to-use mod. Source code and full
documentation: see the repository root `README.md`.

## Quick Start

1.  Add this folder to your Arma 3 launcher as a local mod.
2.  In Eden, select objects and check **"Create as simple object?"** in Object Attributes.
3.  Use the **TBD Tools** menu in the Eden menu bar:
    *   **TBD Tools > TBD Global Library (Saved Groups)** — composition library
    *   **TBD Tools > CSO Operations** — Simple Object tools

> **Note**: This mod uses the `TBD_DB_x64.dll` extension. Make sure the DLL is
> not blocked by Windows (right-click > Properties > Unblock if needed).
